bluebox eurorack mod

Custom firmware v0.14 for the 1010music bluebox eurorack edition, patched in your browser. What it adds

Install at your own risk. This is unofficial firmware, not made or supported by 1010music. Any custom firmware carries some risk of bricking your module or losing projects. Keep your stock firmware file and back up your SD card first.
  1. Get the official bluebox eurorack firmware version 1.5.1 (BLUEEURO.BIN) from 1010music.
  2. Choose that file below. It stays on your computer: the patching happens in this page.
  3. Save the modded BLUEEURO.BIN, copy it to the root of the microSD card and install it like a 1010music update by booting while holding the A button. If your browser saves it as BLUEEURO (1).BIN, rename it to BLUEEURO.BIN first.

Going back to stock: install your stock firmware file the same way.
